A Windows DAW you can actually run.

Airdour keeps the Ardour engine and drops the GTK2, X11, and ASIO baggage. Direct2D draws the session. WASAPI shared plays it beside the rest of the desktop. An MCP server on localhost lets an assistant run the transport.

win_ardour

The shell is a window, not a toolkit port.

C++17, Direct2D 1.0, and DirectWrite. Layout follows per-monitor DPI. The UI thread paints and takes input. Disk, plugin scan, and DSP stay off it.

01

Editor

Stacked audio lanes draw waveforms from mipmapped peaks. Split at the playhead, fade, trim, duplicate, and bounce in place without leaving the lane.

02

Piano roll

Click-drag notes, trim length, drag velocity, quantize, and step in from the QWERTY keys. Chord, arp, and scale lock sit on F5–F7.

03

Mixer

Faders, pan, mute, solo, and record arm, plus the ACE slot on the strip. Inserts can stack in a per-track rack and on the master.

04

Meters

Spectrum on Y, a phase goniometer on X, and an approximate ITU-R BS.1770 LUFS meter on J. Clip hold stays visible until you clear it.

libardour · wasapi

Shared mode on purpose.

The audio callback runs in WASAPI shared mode, at MMCSS Pro Audio priority. The device stays available to the browser and the rest of the system. The backend walks the hardware period ladder and converts float32, int16, int24, and int32 on the way in.

In the box

  • ACE Reverb, Compressor, EQ, Delay, Limiter, and Gate
  • ACE Reasonable Synth on MIDI tracks, with no soundfont to install
  • RubberBand time-stretch and pitch-shift on a region
  • VST3 from the standard Windows folders and VST3_PATH
  • 32-bit VST2 through ardour-vst2-bridge-x86.exe, out of process
  • Headless master bounce to 16-bit WAV

mcp_http · experimental

An assistant can drive the session.

Enable MCPHttp under Preferences → Control Surfaces. The server listens at http://127.0.0.1:4820/mcp. Tool names use a slash: transport/play, tracks/add, plugin/set_parameter, midi_note/import_json.

  • transport/playStart, stop, locate, loop, record
  • tracks/addTracks, buses, faders, pan, mute, solo
  • plugin/addScan, insert, bypass, set a parameter
  • region/splitMove, split, gain, normalize
  • midi_note/import_jsonNotes in bars and beats, drums included

Codex, pointed at the local server

codex mcp add ardour_http \
  --url http://127.0.0.1:4820/mcp

The surface speaks streamable MCP over HTTP, not SSE. Underscore and dotted tool names are accepted as aliases. It binds to localhost only.
